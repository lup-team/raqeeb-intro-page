# رقيب — دليل الفتح والتعديل والنشر

## ما الموجود؟

موقع HTML / CSS / JavaScript بلا تثبيت أو اشتراكات أو خطوات بناء. العربية افتراضية مع زر English، وثلاث محطات تفاعلية، وتصميم للهاتف والكمبيوتر. لا توجد نماذج أو تحليلات أو تخزين للزوار. الرابط الخارجي الوحيد في الصفحة هو Instagram: https://www.instagram.com/lupteam_/

## الهوية والصور — النسخة الثانية

- `assets/hero-oman.png`: صورة هيرو جديدة مولّدة بالأداة المدمجة، بدقة أصلية 1122×1402، مستوحاة من المشهد العُماني في الكارد المرفق. هي مشهد تصوّري وليست توثيقًا لزيارة أو موظف حقيقي.
- `assets/raqeeb-original.png`: ملف الهوية الأصلي المرفق، محفوظ دون تغيير. يعرض الهيدر رمز الدرع والخريطة وحده بواسطة نافذة SVG محددة، فلا تظهر الكتابة العربية أو الإنجليزية في الشعار.
- الألوان مستوحاة من ملفي الهوية والكارد: أخضر داكن `#032E29`، أخضر رئيسي `#063E34`، عاجي `#F3F0E7`، وذهبي رملي `#DDC28E`. هذه ألوان تنفيذ للموقع مستخرجة بصريًا من المرجع، وليست ادعاءً بأنها رموز دليل هوية رسمي.
- لا يوجد شعار LUP في الموقع.
- النصوص تعرض فكرة نموذج أولي فقط، بلا بيانات منشآت، نتائج مختلقة، أو تفاصيل تنفيذ المشروع.

## 1. افتح الموقع الآن

1. نزّل `raqeeb-brand-v2.zip` ثم انقر عليه بالزر الأيمن واختر **Extract All / استخراج الكل**.
2. افتح المجلد المستخرج `raqeeb`.
3. انقر مرتين على `index.html`. يعمل الموقع مباشرة في المتصفح، حتى دون إنترنت.
4. جرّب زر English، المحطات الثلاث، «اكتشف الفكرة»، ثم إعادة الرحلة.

## 2. افتحه في VS Code

1. افتح VS Code.
2. اختر **File → Open Folder** ثم اختر مجلد `raqeeb` المستخرج.
3. افتح الملفات التالية للتعديل:
   - `index.html`: ترتيب الأقسام والعناصر؛ والنص العربي الأولي الظاهر قبل تشغيل JavaScript.
   - `styles.css`: الألوان، الأحجام، المسافات، وتصميم الهاتف. تخصيص الهوية في القسم الأخير الموسوم `Raqeeb identity`.
   - `script.js`: نصوص العربية والإنجليزية داخل `copy`، ومحتوى المحطات داخل `steps`.
   - `assets/hero-oman.png`: الصورة الجديدة.
4. احفظ بـ **Ctrl+S** ثم حدّث المتصفح بـ **Ctrl+R**. لا تحتاج إلى Terminal أو npm أو إضافة مدفوعة.
5. عند تعديل نص ثابت بالعربية، حدّث نسخته في `index.html` وفي `copy.ar` ليبقى متسقًا بعد تبديل اللغة.

## 3. رمز الهوية

الشعار مضاف بالفعل. نافذة العرض التالية تعرض رمز الدرع فقط من الملف الأصلي:

```html
<a class="brand" href="#home" aria-label="رقيب — Raqeeb">
  <svg class="brand-mark" viewBox="65 235 530 625" role="img" aria-label="رمز رقيب">
    <image href="assets/raqeeb-original.png" width="1448" height="1086"/>
  </svg>
</a>
```

عند استبدال ملف الهوية بملف مختلف الأبعاد، يجب تحديث نافذة العرض. يُفضل استخدام نسخة مستقلة من رمز الدرع إن توفرت لاحقًا.

## 4. انشر مجانًا على GitHub Pages

تحتاج إلى حساب GitHub مجاني ومستودع **Public**. لا تحتاج إلى بطاقة دفع أو نطاق مدفوع.

1. سجّل الدخول إلى https://github.com ثم اضغط **+ → New repository**.
2. سمّه `raqeeb` واختر **Public**، وفعّل **Add README**، ثم اضغط **Create repository**.
3. من صفحة المستودع اختر **Add file → Upload files**.
4. افتح مجلد `raqeeb` المستخرج، وحدد محتوياته: `index.html` و`styles.css` و`script.js` ومجلد `assets` والدليل. اسحبها إلى GitHub، ثم اضغط **Commit changes**. ارفع الملفات المستخرجة، وليس ZIP. يجب أن يظهر `index.html` مباشرة في جذر المستودع، وليس داخل مجلد إضافي.
5. إن لم يظهر ملف `.nojekyll` ضمن الملفات المخفية، اختر **Add file → Create new file**، وسمّه `.nojekyll`، ثم احفظه. الملف فارغ.
6. افتح **Settings → Pages**.
7. تحت **Build and deployment** اختر **Source → Deploy from a branch**.
8. اختر **Branch: main** ثم **/(root)** واضغط **Save**.
9. انتظر اكتمال النشر؛ قد يستغرق حتى 10 دقائق. حدّث صفحة Pages واضغط **Visit site**.
10. سيكون الرابط بالشكل `https://YOUR-USERNAME.github.io/raqeeb/`؛ استخدم الرابط الذي يعرضه GitHub فعليًا.

إذا ظهر 404: تأكد أن `index.html` في الجذر، وأن الفرع `main` والمجلد `/(root)` محددان، وأن النشر اكتمل في تبويب Actions.

لتحديث الموقع لاحقًا: عدّل ملفاتك في VS Code، ثم ارفع الملفات المعدلة إلى نفس المستودع واعمل Commit. سيُعاد النشر تلقائيًا.

## 5. اربطه ببطاقة QR

بعد اكتمال النشر، انسخ رابط **Visit site** وضعه في رمز QR ثابت يشير مباشرة إلى رابط GitHub Pages. اختبر الرمز بكاميرا الهاتف، ثم جرّب العربية والإنجليزية والمحطات الثلاث. لا تضع مسار الملف المحلي أو رابط المستودع بدل رابط الموقع. لا تحتاج إلى خدمة QR باشتراك.
